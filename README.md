## 📌 Introduction

The objective of this mini-project is to design and physically construct a **2-bit Binary Ripple Carry Adder** from scratch using **discrete NPN Bipolar Junction Transistors (BJTs)** rather than pre-packaged integrated circuits (ICs).

This project applies fundamental principles of **semiconductor switching, Boolean algebra, digital logic, and transistor-based circuit design**.

A binary adder is a fundamental digital logic circuit used to perform arithmetic addition of binary numbers. In modern computing systems, adders form an essential part of the **Arithmetic Logic Unit (ALU)** within processors.

In this project, two 2-bit binary numbers are added:

```text
A = A1 A0
B = B1 B0
```

The resulting output consists of three bits:

```text
      A1 A0
    + B1 B0
    --------
    COUT S1 S0
```

The circuit consists of two addition stages:

1. **Least Significant Bit (LSB) Stage**

   * Computes `A0 + B0`.
   * Generates the first sum bit `S0`.
   * Generates a carry `C1`.

2. **Most Significant Bit (MSB) Stage**

   * Computes `A1 + B1 + C1`.
   * Generates the second sum bit `S1`.
   * Generates the final carry `COUT`.

By implementing the entire system using discrete BJT components, this project demonstrates the relationship between **transistor-level switching and digital computation**.

# ⚙️ Working Principle and Theoretical Context

## 2.1 Ripple Carry Architecture

A multi-bit binary addition circuit can be constructed by cascading individual adder stages.

The architecture is called a **Ripple Carry Adder** because the carry generated by one stage is passed to the next stage.

For the 2-bit implementation:

```text
          LSB Stage                  MSB Stage

 A0 ───────┐
           │
 B0 ───────┤
           │
           ▼
      ┌───────────┐
      │   Adder   │
      │  Stage 0  │
      └─────┬─────┘
            │
            ├────────── S0
            │
            │ C1
            ▼
      ┌───────────┐
 A1 ─►│   Adder   │
 B1 ─►│  Stage 1  │
 C1 ─►│           │
      └─────┬─────┘
            │
            ├────────── S1
            │
            └────────── COUT
```

The key relationship is:

```text
C1 = Carry generated by the LSB stage

C1 → Cin of the MSB stage
```

Therefore, the MSB stage cannot produce its final output until the carry from the LSB stage has been determined.

### Propagation Delay

The time required for the carry signal to travel from one adder stage to the next is known as **carry propagation delay**.

In discrete transistor logic, this delay can become more noticeable because the signal passes through multiple transistor switching stages.

# 🔌 Circuit Architecture and Signal Integrity

## 3.1 Logical Block Diagrams

Before constructing the circuit using discrete transistor logic, the overall architecture can be represented using standard digital logic blocks.

The fundamental building block is the **Half Adder**.

Two Half Adders combined with an OR gate can be used to construct a **Full Adder**.

### Half Adder

A Half Adder performs the addition of two single-bit binary inputs:

```text
A + B

SUM   = A ⊕ B
CARRY = A · B
```

### Full Adder

A Full Adder performs:

```text
A + B + Cin
```

with the following equations:

```text
SUM  = A ⊕ B ⊕ Cin

COUT = AB + Cin(A ⊕ B)
```

### Full Adder Using Two Half Adders

```text
             ┌──────────────┐
A ──────────►│  Half Adder  │──── X ─────┐
B ──────────►│      HA1     │             │
             └──────┬───────┘             ▼
                    │ C1              ┌──────────────┐
                    │                 │  Half Adder  │──── SUM
                    │                 │      HA2     │
Cin ────────────────────────────────►│              │
                                      └──────┬───────┘
                                             │ C2
                                             ▼
                                      ┌────────────┐
                                      │    OR      │──── COUT
                                      └────────────┘
```

## 3.2 Discrete Transistor XOR Implementation

The **XOR gate** is one of the most important components of the Full Adder.

Implementing an XOR gate using discrete NPN transistors requires careful transistor staging and isolation.

Simply connecting transistor bases together can result in incorrect logic operation or unwanted current paths.

The implemented discrete XOR structure uses isolated transistor bases driven through **10 kΩ resistors**.

The XOR implementation can be understood through three functional stages:

### Stage 1 — Series NAND / Input Detection

The first stage detects the condition:

```text
A = 1
B = 1
```

This condition is associated with the blocking state of the XOR output.

### Stage 2 — Ground Control

The second transistor acts as a switching control element.

When both inputs are HIGH, the transistor state changes and interrupts the required ground path.

### Stage 3 — Parallel Output

The final stage provides the output for the conditions:

```text
A = 0, B = 1

or

A = 1, B = 0
```

This produces the XOR behavior.

The implemented transistor XOR produces an **active-low output**, which requires an additional inverter before being used by the next logic stage.

---

## 3.3 Inverter Bridge Topology

Since the discrete XOR implementation produces an active-low signal, an additional **single-transistor NOT gate** is used.

The inverter converts:

```text
Active-Low Logic
      ↓
Transistor Inverter
      ↓
Active-High Logic
```

This restores the conventional digital logic representation:

```text
Logic 0 → approximately 0 V

Logic 1 → approximately +5 V
```

The corrected signal can then be passed to the next stage of the ripple carry adder.


```text
11₂ + 11₂ = 110₂
```

Since the maximum result requires three bits, the output is:

```text
COUT S1 S0
```

# 🧪 Results

The constructed discrete transistor circuit successfully performs the arithmetic addition of two 2-bit binary numbers:

```text
A1A0 + B1B0
```

The final output is displayed using three LEDs representing:

```text
COUT → Final Carry
S1   → Second Sum Bit
S0   → Least Significant Sum Bit
```

The hardware operation was verified against the theoretical binary addition truth table.

### Tested Operational States

| Operand A | Operand B | Expected Output | Hardware Indication     |
| --------- | --------- | --------------- | ----------------------- |

The hardware testing demonstrated that the discrete transistor XOR configuration successfully generated the required sum logic without unwanted short circuits.
